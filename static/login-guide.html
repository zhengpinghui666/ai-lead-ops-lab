iPhone 短信转发

返回账号登录

使用系统快捷指令接收短信，由 Scriptable 在手机上提取验证码并转发给自己的中转。电脑在当前登录页填写，再核对抖音账号身份。

先在电脑“账号登录”中确认中转连接可用，再配对手机并测试蜂窝网络。Cloudflare 首次部署需要先完成注册邮箱验证。

1. 安装手机脚本

  1. 在 iPhone 安装 Scriptable。
  2. 下载 ClubOps 登录转发脚本，转存到自己的 iPhone。在 Scriptable 新建脚本，将文件的全部内容粘贴进去，命名为 ClubOps 登录转发。这是 JavaScript 脚本，不是苹果 .shortcut 安装文件，不需要 Mac 签名。
  3. 云端部署后，手机也可从自己的中转地址加 /iphone-script 下载相同脚本；下载内容不包含配对凭证。

2. 配对手机

  1. 电脑进入“账号登录”，完成中转地址绑定和连接检查，点击“显示手机配置”。
  2. 在手机运行刚创建的 Scriptable 脚本，将电脑显示的完整 Scriptable 配置 JSON 粘贴到配置框，选择“检查并保存”。只有地址鉴权检查成功后才保存。
  3. 配对信息保存在 Scriptable 的 Keychain 中。无需把凭证写到代码或快捷指令动作中；也不要把配置放进公开分享链接。

3. 先测蜂窝网络

  1. 电脑点击“测试手机转发”。这只创建合成连接测试，不向抖音请求短信。
  2. iPhone 关闭 Wi-Fi、保持蜂窝数据，在 Scriptable 运行脚本，选“手动连接测试”，输入电脑显示的完整测试文字。
  3. 手机出现“验证码已转发”，电脑出现“手机连接测试通过”，两边才算这一项测试通过。只看到“手机已连接中转”还没有验证提交与取回。

4. 绑定短信自动化

  1. 在系统“快捷指令”中新建 ClubOps 登录转发：添加“从输入中获取文本”，输入选择“快捷指令输入”。
  2. 添加 Scriptable 提供的 Run Script／运行脚本 动作，选择同名脚本，把上一步文本设为该动作的 Parameter／参数。保持“在 App 中运行”关闭，以便后台执行。首次访问中转域名时先完成设备提示的许可。
  3. 在“自动化”里创建“信息”触发：按自己的抖音短信设置发送人或内容包含“抖音”的条件，选择系统提供的立即运行方式。
  4. 动作设置为“运行快捷指令：ClubOps 登录转发”，并把收到的信息正文传给快捷指令输入。不要把通知标题或空内容作为输入。
  5. 脚本在手机上检查品牌及唯一的 4–8 位验证码，再核对电脑正在等待的账号、任务和期限。不要增加“显示输入／显示结果”动作，以免短信或验证码出现在屏幕上。脚本输出只有状态与说明。

日常状态怎么看

手机结果含义与下一步
验证码已转发中转已接收；继续看电脑是否填写并完成身份核对。
没有等待任务电脑未在等待本次验证码，短信不上传。
账号不一致／已过期停止转发，在电脑检查本次登录；保持手机时间自动设置。
已尝试／结果尚未确认不重复提交。在原登录页手动处理，或结束任务后再开始。

3 分钟是中转任务期限。脚本记录开始处理输入的时间，不等同于运营商短信送达时间；请让短信自动化立即执行，不要重放旧短信。任务编号与期限用于重复提交保护，完整短信与验证码不写入 Keychain 或日志。

iPhone 安装、首次许可、锁屏触发和真实短信自动登录还需要实机验收。保留有效登录态，等自然需要重新登录时验证完整流程。保存配置不会启动采集或发送私信。
